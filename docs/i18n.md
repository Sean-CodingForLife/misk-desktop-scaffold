# 多语言

## 结构

- 内置语言：`en-US`、`zh-CN`。
- 命名空间：`core`、`workspace`、`tasks`；模块自带 `locales/`。
- core 语言包：`src/renderer/src/core/i18n/locales/`。
- 模块通过 `ctx.i18n.add(locale, namespace, messages)` 注册；资源会同时镜像到 `core` 命名空间，
  这样共享 UI 里直接 `useTranslation()` 也能取到模块 key。

## 解析顺序

1. 设置里的 `locale`。
2. 系统 `app.getLocale()`。
3. `en-US`。

`zh` 会回退到 `zh-CN`；未知语言回退 `en-US`。

## 使用

```tsx
import { useTranslation } from 'react-i18next'
import { useLocalize } from '@renderer/core/i18n'

const notes = { key: 'notes.main.title', ns: 'notes', fallback: 'Notes' }

function NotesView() {
  const { t } = useTranslation('notes')
  const localize = useLocalize()
  return <h1>{localize(notes)}</h1>
}
```

- 插值使用单花括号 `{name}`（已在 i18n 初始化时配置 prefix/suffix）。
- 元数据统一用 `LocalizedText = string | { key, ns?, fallback? }`。
- 日期/数字用 `Intl`，跟随当前语言。

## 模块语言包

```ts
ctx.i18n.add('en-US', 'notes', enUS)
ctx.i18n.add('zh-CN', 'notes', zhCN)
```

key 建议加模块前缀。`npm test` 会检查 core、workspace、tasks 的 en/zh key 是否对齐。

## RTL

`directionFor(locale)` 设置 `<html dir>`；样式使用逻辑属性。当前没有 RTL 翻译，但机制可用。
